# 사주 리포트

한국어 **만세력 계산 + 명리 규칙 + AI 해석**을 분리한 사주 분석 웹사이트입니다.

이 프로젝트는 “생년월일을 넣으면 AI가 운세 글을 쓰는 사이트”가 아닙니다.

```text
사용자 입력
   ↓
[만세력 계산 엔진]   ← 천문력/절기로 사주팔자를 계산 (항상 같은 답)
   ↓
사주 원국 JSON
   ↓
[명리 규칙 엔진]     ← 신강/십성/신살/대운/세운/용신
   ↓
[AI 해석 엔진]       ← 계산된 JSON만 읽고 문장을 씀 (선택)
   ↓
웹 화면
```

개발을 처음 해보는 사람도 아래 순서만 따라 하면 컴퓨터를 자기 웹사이트로 띄울 수 있습니다.

---

## 실행 방법

```bash
npm install
npm test
npm run dev
```

브라우저에서 [http://localhost:3000](http://localhost:3000) 을 엽니다.

언어:

- 한국어 `/ko`
- 스페인어 `/es`
- 폴란드어 `/pl`

- `npm install` : 필요한 부품을 받습니다.
- `npm test` : 사주 계산이 맞는지 자동 검사합니다.
- `npm run dev` : 내 컴퓨터에서 사이트를 켭니다. 종료는 `Ctrl + C`.

2001-03-23 13:00 대한민국 안산 남성은 항상 아래와 같습니다.

| 기둥 | 간지 | 한글 |
| --- | --- | --- |
| 년주 | 辛巳 | 신사 |
| 월주 | 辛卯 | 신묘 |
| 일주 | 乙酉 | 을유 |
| 시주 | 癸未 | 계미 |

13:00은 **未시가 시작되는 시각**입니다. 12:59는 午시, 13:00은 未시입니다.

대략 시간(예: 12:00~14:00)을 넣으면 사이트가 오시/미시 비교를 제안합니다.

## 폴더

```text
src/app/page.tsx               첫 화면
src/app/result/page.tsx        결과 화면
src/app/privacy/page.tsx       개인정보처리방침
src/app/api/analyze/route.ts   계산 API
src/lib/saju/                  만세력 + 명리 계산 (AI 없음)
src/lib/interpret/             한국어 리포트 / 선택적 AI 윤문
src/components/                입력폼, 결과 카드
```

## AI 키 (없어도 됨)

`.env.local` 파일:

```bash
OPENAI_API_KEY=sk-여기에_키
```

키는 서버에만 둡니다. 입력 화면의 **고급 설정 → AI 문장 윤문 사용**을 켜야 AI를 부릅니다. 이름은 AI에 보내지 않습니다.

## 개인정보

- 기본값은 서버에 저장하지 않음
- 결과는 본인 브라우저 임시 저장소에만 남음
- 결과 화면의 **입력값 삭제**로 지울 수 있음
- 자세한 내용: `/privacy`

절기·음양력은 MIT 라이선스 `tyme4ts`를 사용합니다.
